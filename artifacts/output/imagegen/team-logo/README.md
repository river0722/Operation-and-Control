- `moon-gap`：月牙、上升的橙色切面和留白间隙组成几何标志，呼应熬夜与差距。横向字标适合软件、文件页眉和队服。

队名为“认清熬夜差距”，学校文字为“汕头大学”。这两种图形是独立原创团队标志。
