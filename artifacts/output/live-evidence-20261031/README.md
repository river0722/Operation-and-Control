## 4.2 坐标说明更正

当前 `CanvasProjection.cs` 中 `ToScreen/FromScreen` 均采用 **X 向右、Y 向下为正**。原清单“Y 向上为正”和 Y 反向公式不符合当前实现。

当前公式为：`x=Xmin+(px−L)/W·(Xmax−Xmin)`，`y=Ymin+(py−T)/H·(Ymax−Ymin)`；计数映射为 `Cx=1000x`、`Cy=1000y`。显示比例与机械轴方向是否一致，仍需实物方向图和两点校验。源码快照及哈希见 `data/source-CanvasProjection.cs`、`data/sources.json`。

## 再次采集

`collect_readonly.py` 仅允许 VERSION/CID/TYPE、I 参数读、轴状态/P/F/V 和两个指定位置偏置读命令；禁止赋值和运动。它拒绝覆盖已有原始记录。再次采样应复制到新目录，并根据现场连接核对地址。`inspect_existing_materials.py` 只读历史日志和 CAD 头信息。
