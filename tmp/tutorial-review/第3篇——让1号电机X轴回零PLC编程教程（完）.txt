回零步骤
位置1：工作台处于正限位和零位之间
往负限位走，检测零位标志直接回零
位置2：电机台处于零位和负限位之间
往负限位走，检测到负限位标志后往正限位走
一段偏置距离，偏置距离须超过零位，变成了
位置1，再同样往负限位走，检测零位标志直
接回零

PLC程序编程
M120->X:$078000,16 ; /*HOME限位标志，常高电平*/ 
M121->X:$078000,17 ; /*正限位标志，常低电平*/  
M122->X:$078000,18 ; /*负限位标志，常低电平*/
M变量  映射到端口，反映限位开关电平
PLC 0 程序使能命令： ENABLE PLC 0  //使能PLC
PLC 0 程序关闭命令： DISABLE PLC 0  //关闭PLC
走偏置距离指令： COMMAND"#1J^200000" //
开启寻找零点运动：COMMAND"#1HOME"
指令语法
I113=0   //软正限位置零
I114=0   //软负限位置零
I122=32   //电机 1手动Jog速度
I123=-1   //电机 1回零搜索速度和方向
I7012=15   //0号编码器（即1号电机）1号通道信号捕捉

例程1 PLC 1
CLOSE
OPEN PLC 1 CLEAR
IF(P801=1)//向左走
	I113=0
	I114=0
	I122=20
	COMMAND"#1J-"  
	P801=2
ELSE   
	IF(P801=2)   
		IF(M120=0)   //到达home标志
			COMMAND"#1J/"  //停止
			P801=3
		ENDIF
		IF(M122=1)   //到达负限位往正走偏置量
			P801=-1
			COMMAND"#1J^200000" //最小1600000
		ENDIF
	ENDIF
	IF(P801=-1)  //在负限位和零点时动作
		IF(M133=1)   //若到位信息为零,是否走往偏执量
			P801=1
		ENDIF
	ENDIF
	IF(P801=3)
		I123=-1
		I7012=15
		COMMAND"#1HOME"
		P801=4
	ENDIF
	IF(P801=4)AND(M211<4000)AND(M211>-4000)
		P801=5
	ENDIF
	IF(P801=5)
		COMMAND"#1HOMEZ"//设为原点
		P801=6 //完成回零
		I113=884000
		I114=-65000
	ENDIF
	ENDIF
CLOSE

例程2 例程回零PLC改动
CLOSE
OPEN PLC 3 CLEAR
IF(P801=1)AND(M122=1)//向左走//801=1左限位为1避免在负限位还往负走
	I113=0
	I114=0
	I122=32
	COMMAND"#1J-"  
	P801=2
ELSE   
	IF(P801=2)    
		IF(M120=0)   //到达home标志
			COMMAND"#1J/"  //停止
			P801=3
		ENDIF
		IF(M122=1)   //到达负限位往正走偏置量
			P801=-1
			M172=200000
			COMMAND"#1J^*"//向正方向运动200000脉冲
			P813=0
		ENDIF
	ENDIF
	IF(P801=3)AND(M140=1) //P801=3并且未处于零位
		I123=-1    //设置回零运动方向为负
		I7013=0   //零点标志回零
		I7012=15    //组合方式，当I7012=15代表的零点限位有低信号
		COMMAND"#1HOME"   //开启寻找零点运动
		P801=4
	ENDIF
	IF(P801=4)AND(M162<4000)AND(M162>-4000) //电机位置在4000～-4000之间时
		P801=5
	ENDIF
	IF(P801=5)AND(M117=1)   //1号编码器捕捉信号
		COMMAND"#1HOMEZ"//将目前位置设置为零位
		P801=6
		I113=884000   //软正限位置为884000
		I114=-65000   //软正限位置为-6500
	ENDIF
	IF(P801=-1) //在负限位和零点
		IF(M140=0) //若到负限位信息为零
			P813=3
		ENDIF
		IF(M140=1)AND(P813=3)
			P801=1 //回到1状态
		ENDIF
	ENDIF
ENDIF
CLOSE

开始回零位置搜索运动。
#1HOME
本命令使寻址电机执行一个回零位置搜索例程。 回零位置搜索运动的特性由电机的 I 变量 Ixx97 和 Ixx19-lxx26 控制，并将编码 I 变量 2 和 3 用于电机位置编码。
注意：在线回零搜索运动命令（＃xHOME）和缓冲运动程序回零搜索运动语句（HOMEn）之间的语法差别。
将当前命令的位置设置为零。

I7mn2   HOMEZ
I7mn2 的以下设置可能会被用到：
• I7mn2 = 0: 直接捕捉
• I7mn2 = 1: 在索引为高时(CHCn)捕捉
• I7mn2 = 2: 在标志 n 为高捕捉
• I7mn2 = 3: 在索引和标志 n 都为高时捕捉
• I7mn2 = 4: 直接捕捉
• I7mn2 = 5: 在索引为低(CHCn)捕捉
• I7mn2 = 6: 在标志 n 为高时捕捉
• I7mn2 = 7: 在索引为低和标志 n 为高时捕捉
• I7mn2 = 8: 直接捕捉
• I7mn2 = 9: 在索引为高时(CHCn)捕捉
• I7mn2 = 10: 在标志 n 为低时捕捉
• I7mn2 = 11: 在索引为高并且标志 n 为低时捕捉
• I7mn2 = 12: 直接捕捉
• I7mn2 = 13: 在索引为低时(CHCn)捕捉
• I7mn2 = 14: 在标志 n 为低时捕捉
• I7mn2 = 15: 在索引为低和标志 n 为低时捕捉
I7mn2
• I7mn3 = 0: HOMEn (回零标志 n)
• I7mn3 = 1: PLIMn (正限位标志 n)
• I7mn3 = 2: MLIMn (负限位标志 n)
• I7mn3 = 3: USERn (用户标志 n)
I7mn3
m为m号电机，n为m号电机上n编码器通道
I7013=0  //0号电机，1通道
I7012=15 //组合方式，检测到低，且是回零标志低
I7mn3 决定哪个限位标志输入将被用于第 m个 PMAC2 类型伺服 IC 的第 n 通道编码计数器的硬件位置捕捉（如果使用的话）。I7mn2 决定是否使用标志和标志的哪个极性能触发触发器。
(用第 m个伺服 IC 的 n 通道，其中 m = 0 到 9，n = 1 到 4)
