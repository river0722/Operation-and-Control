# 上位机操作与验收

本次按第三组分工表补齐上位机软件，采用用户确认的 ASCII DXF 范围。实机参数尚未提供，当前完成软件与模拟验证。

2026-10-14 增加手动运动保护、到位与停稳确认、每轴使能/去使能/复位、诊断报警、配置保存及日志留存，详见[电机调试与保护说明](电机调试与保护说明.md)。

## 使用方法

1. 运行 `src/Operations Control/bin/Release/Operations Control.exe`，选择模拟模式并连接。
2. 在“绘图与运行”页导入 `examples/course-shapes.dxf`，或添加直线、圆、圆弧、五角星，也可在左上方画布自由绘图。
3. 在“插补”下拉框选择 PVT、Spline1、直线插补或圆弧插补，设置目标速度和间距，点击“生成规划”。PVT 默认勾选“连续 PVT”，首尾相接的笔画会合并为连续轨迹；取消勾选可保留每条笔画的独立停机。PVT 还需设置路径加速度，并受各轴速度、加速度约束；上位机生成预览，下发几何数据、参数和通用算法，由下位机计算速度与段时间。其他模式保留“加速度：不设限”。在“程序”页查看或保存规划程序，并编辑自定义程序。具体变量分配与执行协议见 [PVT 下位机参数化规划](PVT下位机参数化规划.md)。
4. 左侧绘图区的橙色十字持续显示当前下位机位置。勾选“平台跟随鼠标”后，从十字附近按下拖动即可启动，起点默认允许 0.5 mm 误差；也可直接抓取当前十字重新开始。鼠标路径按顺序保留并通过 PVT/Spline1 同步插补两轴，不计算鼠标速度，不用鼠标事件间隔安排运动。段时间由几何规划和各轴参数决定；转角、折返和闭环不会被最新终点覆盖。保持按住而停止移动鼠标时，平台继续执行队列中的路径。松开、失焦或移出画布会取消剩余轨迹并停止两轴。完整规划路径仍点击“运行”，右画布显示控制器反馈。底部全局区的“停止”或 Esc 可中止；关闭程序会先请求停止。
5. 在“分析”页点击“分析”查看偏差与滞后，再“导出数据”。停止的数据会标为未完整运行。
6. “设置”页提供坐标参数、图形变换、使能、失能和机械回零。模拟演示保持 PLC = -1，选择目标轴后开始回零。“手动控制”和“日志”也在主窗口内。

运行期间锁定手动命令、模式和相关参数，切换页面仍可使用底部全局区的停止按钮。连接模式和状态固定在顶部；绘图与规划工具仅在“绘图与运行”页显示。路径或规划参数改变后需重新规划。多笔画之间包含定位转移，当前没有抬笔或刀具开关控制。

直线插补生成 PMAC `LINEAR` 指令。圆弧插补识别连续不少于四个、按相同方向排列的同圆采样点，且相邻圆心角不超过 30°；识别成功的部分生成顺时针 `CIRCLE1` 或逆时针 `CIRCLE2`，其余部分保持直线。整圆和长段会拆分；转移段保持直线。两种模式均显式设置预留坐标系的 `Isx13=5`、`TA0 TS0`，以 `TM` 指定段时间，并为圆弧指定 `NORMAL K-1` 和增量圆心向量 `INC(R)`。模拟器按理想直线或圆弧计算位置；控制器分段插值和实际伺服误差需实机验证。选择这两种模式时，鼠标随动使用 PVT。插补选择可随设备配置保存，导出的 `planned.csv` 追加段类型、圆心和扫角字段。

## 输入与参数

DXF 支持 LINE、ARC、CIRCLE、LWPOLYLINE（含 bulge）、普通二维 POLYLINE，以及带控制点和节点矢量的非周期 SPLINE。按 `$INSUNITS` 换算单位；无单位文件使用界面指定比例。

DWG 需先转 ASCII DXF。块、文字/标注、三维、倾斜法向、周期样条和仅拟合点样条会明确报错，请在 CAD 中分解或转换后导入。图形平移改变输入点，不设置独立 G54 工件坐标系。

| 参数 | 默认值或规则 |
| --- | --- |
| 模拟标定 | X/Y 电机 1/2；100 ct/mm；各轴 −10～+10 mm |
| 目标速度 | 5 mm/s；同时受 X/Y 每轴最大速度和最短段时间 50 ms 限制；PVT 还受路径及各轴加速度上限约束 |
| PVT 路径加速度 | 20 mm/s²；仅用于完整 PVT 路径，包括转移段 |
| 点间距 | 0.5 mm，长边分段，保留原有转角 |
| DXF 采样弦差 | 0.01 mm；样条采用自适应近似 |
| 模拟滞后 | 80 ms，可修改 |
| 反馈请求间隔 | 50 ms，上一查询未完成时不积压请求 |
| 起点 / 终点检查 | 起点变化超过 0.01 mm 要求重规划；终点偏差超过 0.05 mm 报错 |
| 容量 | 输入/规划最多 20000 点或段，运行最多 1 小时，反馈最多 100000 点 |

这些是软件演示与检查参数，不是实机定位精度指标。真实速度、行程、比例和精度要求须按设备确定。

## 实现原理

流程为：输入图形 → 单位与坐标转换 → 路径校验 → 规划 → 程序预览 → 执行和采样 → 分析/导出。

GUI 采用事件驱动，输入变更使旧规划失效；连接、反馈、轴状态及实机配置决定操作是否可用。解析、规划和分析在后台计算；控制命令通过独立 STA 会话串行发送。

| 层次 | 职责 |
| --- | --- |
| 主窗口与路径模型 | 用户交互、笔画、运行状态及完整采样 |
| 几何、DXF、规划和分析服务 | 图形转换、轨迹计算、程序生成及误差统计 |
| ControllerSession | 命令组合、反馈读取、停止与取消 |
| IControllerTransport 的实机/模拟实现 | 屏蔽 PcommServer COM 与设备通信细节 |

上位机针对 Turbo PMAC。`#nP` 读取计数位置，`#n?` 读取电机状态，`&n??` 读取坐标系状态。计数除以 ct/mm 得到毫米；XY 顺序查询并各自记录查询中点时间，不是同步锁存采样。

鼠标跟随保留有序的毫米路径点，约 100 ms 整理后通过旋转缓冲区连续追加同一坐标系中的 X/Y 轨迹段。鼠标时间戳只用于整理缓冲、积压检查和延时统计，不计算画速，不参与段时间计算。几何合并误差不超过 0.02 mm，并检查单调投影以保留折返；PVT 在转角停速，Spline1 使用固定 TM20 和顶点重复控制点到达转角后再转向，避免切角。通信暂满时保留原段并等待，不跳过旧路径追赶新终点。完整路径仍生成为坐标系程序，由控制器同步插补 XY：`#1->100X` 等语句定义轴比例；`ABS` 使用绝对坐标；PVT 指定位置、末速度及段时间，SPLINE1 使用等时三次 B 样条。程序使用 `I42=0` 和 `Isx90=1000`，单位为 mm、mm/s、ms。坐标系 1/9/10/16 的时间单位变量分别为 I5190/I5990/I6090/I6690。

PVT 是三次位置/速度插补。连续 PVT 会把首尾相接的绘图笔画合并，使共享点成为内部节点；普通折点按转角平滑降速，真正反向时才停速。`DWELL 0` 只用于转移/独立笔画边界和程序结束，不插入连续 PVT 记录之间。完整 PVT 程序先扫描几何数据，计算满足路径及各轴速度、加速度约束的时间系数，再扫描生成运动段；上位机同算法预览并检查行程。Spline1 保留原来的速度约束和统一 TM，不按加速度延长时间；它会圆滑转角，不保证经过每个输入点。两种规划的单段时间均不超过 4000 ms。

每轴的最大速度和最大加速度在“诊断与配置”页设置，单位分别为 `ct/ms` 和 `ct/ms²`；最大加速度只要求为正数，输入范围受 decimal 数值类型限制。实机参数需按驱动器和机械配置填写。鼠标轨迹随动按这些轴规划参数计算几何段时间，检查 PVT 段内速度与加速度极值，Spline1 按固定 TM20 细分控制点；这些计算不使用鼠标速度。完整路径、手动定位和回零仍使用各自的参数流程。

`&nB程序号R` 启动，`&nA` 中止本次路径程序。完整 PVT 程序的第一次启动只计算并暂停；上位机等到 Q209=2 且坐标系停止、到位后，发送 `&nR` 开始运动与计时。所选坐标系需要预留 Q200～Q269。完成判定同时检查程序结束、轴/坐标系到位、终点偏差和故障状态。模拟器执行数学规划，不解释任意下载脚本；新增程序子集测试执行生成算法，但实际固件执行仍需验证。

## 导出与分析

| 文件 | 内容 |
| --- | --- |
| drawing.csv | 原始采样点、笔画号 |
| planned.csv | 规划段起止位置、速度、时间、转移标记和停机边界 |
| actual.csv | 反馈、每轴采样时间、参考位置、误差、查询耗时及来源 |
| analysis.txt | RMS/最大误差、滞后与采样统计、完成状态 |
| program.pmc | 本次运行对应的程序 |

数据独立于画布保存。时间配对误差按每轴查询中点计算“实际位置−同时刻计划位置”；轮廓偏差取反馈点到原始折线的最短距离，按计划排除转移阶段。前者包含跟随滞后，后者不能证明沿路径的时序或完整覆盖，转移边界附近的滞后也会影响统计。

滞后估计在 ±1000 ms 范围以 10 ms 步长匹配轨迹。样本不足、运动量过小或结果到达搜索边界时不给出可靠值；周期轨迹可能有歧义。已用 80 ms 已知滞后及 0.2 mm 已知偏移验证计算。

偏差主要来自图形离散、Spline 圆滑、标定、传动/伺服响应及通信采样。改进顺序为：核对单位与标定，调整点距及目标速度，使用控制器缓冲执行；精密验收采用控制器同步采集与量具。仅缩短界面 Timer 间隔不能消除通信和机械延迟。

## 实机待验收

需要确定控制器/固件型号、X/Y 电机号、ct/mm、轴方向、允许行程、回零参数、专用坐标系/程序号、PLC 号和精度指标。实机模式须重新应用标定并确认配置。

生成程序会定义所选轴映射、清空指定程序、设置全局 I42 及对应 Isx90；所选坐标系必须专用且没有其他轴。“设置”页的“机械回零”使用已部署的 PLC1，先发送 `ENABLE PLC 1`，等待至少 500 ms 后再发送 `P801=1`；等待期间可取消启动；PLC 先完成电机 1 的 X 回零，再启动电机 2 的 Y 回零。上位机读取 `P801/P802`，两者均为 6 且两轴速度零、已到位时才报告完成，不依赖执行 HOMEZ 后的 Home Complete 位。入口允许已停稳轴处于负限位，由 PLC 退让；回零轴与 PLC 选择仅供模拟模式使用。停止或解除等待会先清零 `P801/P802` 再停止或去使能两轴，保持 PLC1 运行。模拟模式使用内置 HOME。手动页的“XY轴回零”按速度与定位加速度直接定位到位置 0，独立于机械回零。

现场仍需验证通信、标定、回零及重复性、双轴程序执行、停止/故障处理和真实轨迹精度。软件停止通过通信队列发送，不能替代硬件急停。本地成果也不能证明周报、Ego 云提交和现场汇报已完成。
