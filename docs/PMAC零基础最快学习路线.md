# PMAC 零基础最快学习路线

适用情况：你已经有 PMAC、伺服驱动器和电机，可以上机。当前资料主要围绕 Turbo PMAC/Clipper，部分实例采用松下 A5 驱动器。实际设备型号和接线方式尚未确认，因此涉及地址、驱动参数和运动距离的内容都需要按实机核对。

第一阶段只定一个目标：独立完成一个轴的通信、反馈检查、低速点动、简单往返运动和回零，并能查看状态、停止运动、备份参数。按每天约 2 小时安排 7 次学习；某一步没通过就继续排查，不必赶进度。设备尚未接好或软件尚未装好时，准备时间另算。

## 2. 上机之前，先认识这些东西

| 名词 | 用小白能理解的话解释 |
|---|---|
| PMAC | 计算运动轨迹并发出控制指令的控制器 |
| 驱动器 | 接收控制指令，向电机提供电流；也有自己的控制参数和报警 |
| 电机 | 真正转动、带动机械运动的部件 |
| 编码器 | 测量位置和转动方向的部件；先确认反馈送到哪里 |
| 使能 | 允许驱动器或控制轴工作；不等于已经发出运动指令 |
| 点动 JOG | 手动让一个电机运动，适合检查方向和短距离移动 |
| 回零 HOME | 用原点开关、编码器标志等寻找可重复的位置基准 |
| 限位 | 防止机械超出允许行程；有硬件开关和软件位置范围 |
| 电机号与坐标轴 | `#1` 指电机 1，`X` 是运动程序里的轴；需先建立映射 |
| 坐标系 | 把需要一起运动的轴组织起来；`&1` 选择坐标系 1 |
| 运动程序 | 描述位置、速度和运动顺序，如移动、停顿、返回 |
| PLC 程序 | 在 PMAC 内循环判断条件，处理回零步骤、开关和联锁；这里不需要另买一台 PLC |
| I 变量 | 设置控制器、轴和运动参数 |
| P 变量 | 保存程序中的数值、步骤或状态 |
| M 变量 | 可指向寄存器或状态位；编号的含义取决于实际定义，不能只凭编号猜用途 |

先把设备型号、控制方式、反馈来源、轴号写到一张纸上。重点分清：驱动器接受“脉冲＋方向”还是“模拟量”，以及 PMAC 读取的是真实反馈还是内部产生的计数。显示位置变化本身并不足以证明电机真的到位。

## 3. 7 次学习安排

主线文件都在 [000 教程](D:/pmac资料/pmac资料/上手教程/调试教程/000%20教程) 中。每次尽量用 30 分钟看资料，其余时间操作和记录。

| 次数 | 优先阅读 | 当次任务 | 通过标准 |
|---|---|---|---|
| 第 1 次：认识系统、建立通信 | 第 0.1 篇通信 PDF；接线说明；硬件手册中对应的供电和接口部分 | 核对设备；连接 PewinPro2；认识 Terminal、Watch Window、Position、Motor Status；备份现有参数和程序 | 稳定连接并读取状态，保存修改前备份 |
| 第 2 次：检查驱动器和反馈 | 入门教程中的反馈检查；若是 A5，读 A5 调试步骤中与实机相符的部分 | 核对驱动器模式、指令接口、使能、报警、反馈方向和计数；验证正负限位及原点输入 | 知道指令和反馈分别走哪条线，相关输入状态与实物一致 |
| 第 3 次：调通一个轴 | 第 1.1 篇 Setup 教程；第 1.2 篇只作查变量补充 | 对照实际接口使用 Setup；在已确认的低速、短行程条件下点动；记录配置；按实际控制结构检查闭环响应 | 能正反点动和停止，方向正确，无持续异常振动或报警 |
| 第 4 次：写简单直线程序 | 第 2 篇；对应的直线运动 TXT；Plot 教程的采集部分 | 理解电机到 X 轴的映射、计数与机械单位换算、INC/ABS、F、DWELL；在确认可用行程后完成短距离往返 | 实际位移与设定相符，返回正确；能读懂期望位置和实际位置曲线 |
| 第 5 次：学习回零 PLC | 第 3 篇；回零 PLC 和启动程序 TXT | 先逐行说明每个状态和退出条件；核对开关极性、寻零方向、偏置量、回零完成状态；增加适合设备的超时和异常退出处理后再试运行 | 可从不同合法起始位置回零，重复结果符合设备要求，异常时能停止 |
| 第 6 次：巩固和排错 | 前面用过的教程；必要时查 SRM | 独立完成连接、状态检查、点动、往返、回零、备份；对实际遇到的问题按通信、输入、使能、模式、运动状态逐项排查 | 脱离教程也能完成单轴流程，并说明故障定位依据 |
| 第 7 次：按目标选方向 | 有第二轴且已独立调通：第 4、5 篇插补；只有一轴：继续巩固 | 两轴设备做低速短路径直线插补；单轴设备练习参数换算、程序和曲线检查 | 两轴动作与规划相符，或单轴操作已能稳定复现 |

第一周可以先停在“单轴调通”。回零是最依赖机械结构和开关位置的环节，花两三次学习完成也很正常。

## 4. 今天具体做什么

1. 记录 PMAC、驱动器、电机的完整型号，以及这次准备学习的轴号。
2. 确认是否已有 Pewin32Pro2 和 Setup 工具。当前目录列表没有看到明确的 Pewin 安装包；伺服目录下的 `setup.exe` 不能仅凭名字当成 PMAC 软件安装包。
3. 先打开 [第0.1篇——TurboPMAC和PewinPro2建立通信](D:/pmac资料/pmac资料/上手教程/调试教程/000%20教程/第0.1篇——TurboPMAC和PewinPro2建立通信.pdf)，按实际控制卡 IP 建立连接。教程中的 `192.6.94.5` 是其说明的出厂默认地址，现场设备可能已修改。
4. 连接成功后，按教程使用 Watch Window 观察 `X:$0` 的数值变化，检查通信与控制卡运行状态；再熟悉 Motor Status、Position 窗口。
5. 上传并备份当前控制器参数、运动程序、PLC 和 M 变量定义；备份驱动器参数。记下设备型号、日期和对应轴号。
6. 今天完成上述内容即可。运动测试留到接线、模式、反馈和停止方式确认之后。

今天的成果是：能连接、能看状态、拿到原配置备份。

## 5. 这些例程需要先核对

这是本次阅读发现的具体问题，不是可以直接下载到设备的调试脚本。

- **点动与回零参数混写。** `程序/1号电机I变量配置.txt` 连续写了 `I122=20` 和 `I122=32`，后者却注释为“回零速度和方向”。SRM 明确规定 `Ixx22` 是点动速度，`Ixx23` 是回零速度和方向；对 1 号电机分别是 `I122` 和 `I123`。因此后一次赋值实际会覆盖点动速度，不会设置回零速度。来源：SRM 印刷页 80、81，PDF 第 100、101 页。
- **回零例程会禁用软件限位。** 例程中的 `I113=0`、`I114=0` 按 SRM 含义会禁用对应软件位置限位。回零完成后还有固定的限位数值，这些必须按实际机械行程和零点位置重新确定。来源：SRM 印刷页 75、76，PDF 第 95、96 页。
- **直线例程会删除现有轴定义。** `UNDEFINE ALL` 会清除轴定义，不能在已有多轴项目上直接照搬整个文件。`OPEN PROG 1 CLEAR` 也会清空指定程序缓冲区，应核对它是否已有程序。
- **比例系数是实例数值。** `#1->1638.4X` 对应例程中的反馈计数及 10 mm 丝杠导程假设，实际比例应按反馈分辨率、倍率、传动比和机械导程核算。不能把电机分辨率、指令脉冲数和 PMAC 反馈计数视为同一个数。
- **Setup 选项取决于指令接口。** 第 1.1 篇例子给交流伺服选择 `stepper`，其解释是该实例采用脉冲控制接口。实际轴也要按输出接口选择，不能只看电机名称。教程中“屏蔽报警”的设置需要单独核对，带机械负载的设备不能以此绕过故障与限位检查。
- **接线说明是特定设备实例。** 该 PDF 写明驱动器型号为 MBDHT2510，针脚、接地和电源连接要对照实机手册。其线色说明不能作为判断 L、N、PE 的依据，强电接线让有经验的人员按端子标识复核。
- **下载、启动和掉电保存需要分清。** 下载文件中的配置段可能立即修改参数；保存运动程序到缓冲区和启动运行是不同操作；是否掉电保留另按手册中的保存流程确认。教程里把下载笼统称为拷入 EPROM，不能据此判断全部内容已持久保存。

首次运动前至少确认：电机和机械已固定，可用行程明确，急停有效，限位输入与实际一致，反馈及输出方向相符。先用确认过的低速、短距离验证。软件点动停止不等同于硬件急停；竖直轴或重力负载要先确认抱闸和支撑条件。

## 6. 暂时后置的内容

第一阶段后置：高级培训、Spline/PVT、C# 上位机、ACC 扩展板、9～12 轴配置、全套寄存器映射，以及深入的 PID 理论。现有 12 轴配置同时改时钟、输出、反馈和多个轴，不适合零基础的首次上机。

单轴稳定后按实际目标继续：

- 做 XY 工作台：第 4、5 篇直线和圆弧插补，再看中级培训相关部分。
- 做连续轨迹：插补基础稳定后学习第 6 篇 Spline/PVT。
- 做电脑操作界面：先能在 Pewin 中完成同样动作，再学第 7 篇 VS+C# 和 PcommServer。
- 做多轴与 IO：先增加一个轴，再读 12 轴配置和扩展板手册，逐轴核对地址与信号。

每次上机只改少量参数，记录“原值、修改值、目的、观察结果”。保留一份能正常运行的配置，这是最快积累经验的方法。
