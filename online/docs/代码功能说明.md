# PMAC 上位机代码功能说明

更新日期：2026-10-13。依据当前 `online/Operations Control` 源码整理，共 57 个 C# 文件，包含设计器、自动生成文件和三个独立检查程序。

本次模块化重构保留原界面。层次、线程及维护约定见[模块化架构与维护说明](模块化架构与维护说明.md)。

项目为 C# WinForms、.NET Framework 3.5 / x86。所有操作集中在主窗口。实机通信使用 32 位 PcommServer COM；实际设备通过以太网连接，以太网设备及 IP 由厂家配置工具设置，当前代码没有直接实现 Socket 通信或 IP 输入界面。

## 1. 程序入口与主窗口

| 文件 | 功能 | 主要入口 |

| [Program.cs](<../Operations Control/Program.cs>) | 程序启动，设置 WinForms 显示方式，打开主窗体 | Main |
| [Form1.cs](<../Operations Control/Form1.cs>) | 装配共享业务与通讯服务，整合页面、绑定按钮事件；显示反馈，处理对话框与窗口生命周期 | IntegrateViews、WireEvents、UpdateState、Run |
| [Form1.Designer.cs](<../Operations Control/Form1.Designer.cs>) | 创建顶部通信区、X/Y 位置、全局停止、主内容区、底部状态及定时器和文件对话框 | InitializeComponent |

Form1 中常用方法：

| 方法 | 作用 |
| --- | --- |
| IntegrateViews | 将 PathView、手动页、程序编辑器和日志嵌入同一个主窗口 |
| WireEvents | 把控件事件接入连接、运动、文件和窗口流程 |
| UpdateState | 根据连接、忙碌、点动、跟随、路径运行和关闭状态更新操作权限 |
| Run | 将控制器操作排入通信线程，完成后报告结果并恢复界面状态 |
| RefreshData / DisplayPosition | 显示统一 FeedbackService 已取得的反馈，更新读数、画布及顶部 X/Y，不再另行查询 |
| StartJog / StopJog | 将点动请求交给 ManualMotionService，保持快速按放命令顺序 |
| BeginDrawing / PumpDrawing / CancelDrawing | 开始、提交和取消鼠标跟随 |
| StopMonitoredAxes | 路径运行时中止路径；其他情况下停止 X/Y 和所选电机 |
| SendCommand | 发送用户输入的单条命令并显示应答 |
| OpenProgram / SaveProgram / DownloadProgram | 读取、保存和下载自定义程序，处理编码及未保存内容 |
| Disconnect / CloseForm | 结束交互、请求停止、断开设备并处理关闭 |

PathView 中的主要方法：

| 方法 | 作用 |
| --- | --- |
| UpdateContext / RefreshState | 接收主窗口模式、轴号和标定，读取共享 OperationState 更新按钮 |
| LoadDrawing / ImportDxf / AddShape | 加载笔画、导入 DXF 或添加典型图形 |
| InvalidatePlan | 图形或参数改变后清除旧规划和程序预览 |
| GeneratePlan | 获取输入与当前位置，后台调用 MotionPlanningService 组合规划与 PMAC 程序生成 |
| StartExecution | 向 MotionWorkflow 提交执行请求，并清理界面的实际轨迹与分析显示 |
| Poll | 请求统一反馈服务采集；运行判定与采样由 MotionWorkflow 完成，页面只显示结果 |
| EnableAxes / StartHoming | 将使能/失能或回零参数提交给 MotionWorkflow |
| StopExecution | 调用 MotionWorkflow.Stop，由业务层取消启动、中止运动和处理停止回调 |
| Analyze / Export / SaveProgram | 计算统计、导出完整运行数据、保存规划程序 |
| Background / CancelPendingWork | 将解析、规划、分析和数据导出放在后台，关闭时使待处理结果失效并停止轮询 |

PathView 通过 ActivityChanged、StatusChanged 和 SnapshotChanged 向主窗口通知忙碌状态、消息和实时位置。

| 文件 | 主要类型 | 功能 |

## 5. Application、Communication、Motion、Files：业务与设备模块

| 文件 | 功能 | 主要方法 |
| --- | --- | --- |
| [IControllerTransport.cs](<../Operations Control/Communication/IControllerTransport.cs>) | 定义实机与模拟共用的连接、断开、命令、下载和释放接口 | Connect、Disconnect、Send、Download、Dispose |
| [PcommTransport.cs](<../Operations Control/Communication/PcommTransport.cs>) | 适配 PCommServer.PmacDevice；选择/打开设备，通过 GetResponseEx 收发 ASCII 指令，通过 Download 下载文件，关闭并释放 COM | Connect、Send、Download、Dispose |
| [SimulatorTransport.cs](<../Operations Control/Communication/SimulatorTransport.cs>) | 模拟 8 个电机的位置、点动、定位、状态、回零和按时间执行的双轴规划；支持滞后和故障注入 | Send、StartPlan、StopPlan、InjectFault |
| [ControllerSession.cs](<../Operations Control/Communication/ControllerSession.cs>) | 委托 StaCommandDispatcher 调度，选择实机/模拟传输，封装 PMAC 命令和统一反馈，执行路径/回零设备操作 | Execute、Jog、Move、ReadFeedback、ReadSnapshot、StartPlan、StopPlan、Home、StopHome |
| [CanvasFollower.cs](<../Operations Control/Application/CanvasFollower.cs>) | 合并最新鼠标目标，限制同类请求积压，设置轴速度并提交双轴目标；取消旧任务并请求停止 | Begin、Submit、Pump、Cancel |
| [DxfReader.cs](<../Operations Control/Files/DxfReader.cs>) | 读取 ASCII DXF，换算单位，解析直线、圆弧、圆、多段线和样条，拒绝异常或不支持的输入 | Read、ReadText |
| [PathGeometry.cs](<../Operations Control/Motion/PathGeometry.cs>) | 创建直线、圆弧/圆和五角星；校验、缩放、平移、重采样；计算距离及点到线段距离 | Line、Arc、Star、Validate、Transform、Resample、SegmentDistance |
| [TrajectoryPlanner.cs](<../Operations Control/Motion/TrajectoryPlanner.cs>) | 将图形生成 PVT 或 Spline 规划；加入转移段，限制速度/加速度/段时间，检查曲线极值和行程 | Build |
| [PmacProgramWriter.cs](<../Operations Control/Communication/PmacProgramWriter.cs>) | 将规划写成 PMAC 程序，包括轴比例、坐标系、程序号、时间单位、PVT/SPLINE1 和段间等待 | Write |
| [TrajectoryAnalysis.cs](<../Operations Control/Motion/TrajectoryAnalysis.cs>) | 计算时间配对误差、轮廓误差、滞后和查询统计；同文件定义 AnalysisResult，导出移至 RunDataExporter | Analyze |

| [MotionWorkflow.cs](<../Operations Control/Application/MotionWorkflow.cs>) | 路径运行、回零、故障、超时及停止重试，独立于界面 | StartExecution、StartHoming、Poll、Stop |
| [OperationState.cs](<../Operations Control/Application/OperationState.cs>) | 共享手动、点动、跟随、计算、运行、回零和停止互斥状态 | WorkflowExecuting、WorkflowBusy、ExternalBusy |
| [ManualMotionService.cs](<../Operations Control/Application/ManualMotionService.cs>) | 手动请求排队、点动顺序和断开清理 | Execute、StartJog、StopJog、Disconnect |
| [FeedbackService.cs](<../Operations Control/Application/FeedbackService.cs>) | 单一反馈来源，在途去重与旧结果丢弃 | Poll、Clear、Updated |
| [MotionPlanningService.cs](<../Operations Control/Application/MotionPlanningService.cs>) | 组合规划算法与 PMAC 程序生成 | Build |
| [IControllerSession.cs](<../Operations Control/Communication/IControllerSession.cs>) | 不包含界面控件的业务设备接口 | Execute、ReadFeedback、StartPlan、Home、Stop |
| [StaCommandDispatcher.cs](<../Operations Control/Communication/StaCommandDispatcher.cs>) | 私有 STA 队列与调用者上下文回调 | Execute、Shutdown |
| [ProgramFileStore.cs](<../Operations Control/Files/ProgramFileStore.cs>) | UTF-8/GBK 程序读写和下载临时文件 | Read、Save、SaveGenerated、CreateTemporary |
| [RunDataExporter.cs](<../Operations Control/Files/RunDataExporter.cs>) | 导出原始点、规划段、完整反馈、报告与程序 | Export |

通信路径为：界面操作 → 业务服务 → IControllerSession / ControllerSession → PcommTransport → PcommServer → 已配置的以太网设备 → PMAC。模拟模式将 PcommTransport 换成 SimulatorTransport。

ControllerSession 的 Execute 委托 StaCommandDispatcher 排队，并通过会话配置的应用 SynchronizationContext 回送结果。Jog、Move、ReadSnapshot 等实际通信方法在该队列内执行；界面不直接调用 COM。

模拟器执行软件规划模型，不解释任意下载脚本。模拟下载成功只表示文件通过检查。

## 8. 主要调用关系与线程

| 操作 | 调用关系 |
| --- | --- |
| 启动 | Program.Main → Form1 → 创建 ControllerSession 和页面 → 绑定事件 |
| 连接 | ConnectionView 按钮 → Form1.Run → ControllerSession.Connect → 实机/模拟传输 |
| 手动运动 | MotionView 事件/按钮 → Form1 → ManualMotionService → ControllerSession.Execute → Jog / Move / Stop |
| 鼠标跟随 | MotionCanvas 事件 → Form1 → CanvasFollower → ControllerSession.MovePair |
| 图形规划 | PathView → DxfReader / PathGeometry → DrawingPath → TrajectoryPlanner → MotionPlan 和 PmacProgramWriter |
| 路径执行 | PathView.StartExecution → MotionWorkflow.StartExecution → ControllerSession.StartPlan → 实机下载并启动，或模拟器执行规划 |
| 执行采样 | PathView.Poll → MotionWorkflow → FeedbackService → ControllerSession.ReadFeedback → TrajectoryRun → 实际画布和顶部位置 |
| 分析导出 | PathView → TrajectoryAnalysis / RunDataExporter → AnalysisResult、CSV、报告和程序 |

界面线程负责控件、绘图和定时器事件；独立 STA 线程串行执行通信；BackgroundWorker 执行 DXF 解析、规划、分析和数据导出。后台结果交回界面线程，取消标记用于丢弃过期任务结果。

手动位置和步长使用 ct、速度使用 ct/ms；绘图和规划使用 mm、mm/s、mm/s²，轨迹时间使用 ms。实际 ct/mm 通过 CanvasSettings 换算。

## 9. 查找和修改入口

| 需要处理的内容 | 优先查看 |
| --- | --- |
| 主窗口布局 | Form1.Designer.cs；运行时整合看 Form1.IntegrateViews |
| 绘图/规划参数及页面 | PathView.Designer.cs、PathView.cs |

| 比例和行程换算 | CanvasView.cs、CanvasModels.cs |
| CAD 导入 | DxfReader.cs |
| 插补算法和生成程序 | TrajectoryPlanner.cs、PmacProgramWriter.cs |
| 偏差、滞后和导出 | TrajectoryAnalysis.cs、RunDataExporter.cs |
| 模拟行为与故障验证 | SimulatorTransport.cs、Tests 下两个检查程序 |

当前实机接口、状态和生成程序按 Turbo PMAC 实现，真实控制器型号尚未确认。手动运动统一保护、控制器侧断联停机、设备配置保存、轴方向/工件零点和 PLC 回零协议仍需完善；这些边界见 [软件开发问题与解决记录](软件开发问题与解决记录.md)。
