# PMAC 上位机代码功能说明

更新日期：2026-10-13。依据当前 `online/Operations Control` 源码整理，共 45 个 C# 文件，包含设计器、自动生成文件和两个独立检查程序。

项目为 C# WinForms、.NET Framework 3.5 / x86。所有操作集中在主窗口。实机通信使用 32 位 PcommServer COM；实际设备通过以太网连接，以太网设备及 IP 由厂家配置工具设置，当前代码没有直接实现 Socket 通信或 IP 输入界面。

## 1. 程序入口与主窗口

| 文件 | 功能 | 主要入口 |
| --- | --- | --- |
| [Program.cs](<../Operations Control/Program.cs>) | 程序启动，设置 WinForms 显示方式，打开主窗体 | Main |
| [Form1.cs](<../Operations Control/Form1.cs>) | 创建通信服务，整合页面，连接按钮事件；处理手动控制、鼠标跟随、反馈、文件、停止和关闭 | IntegrateViews、WireEvents、UpdateState、Run |
| [Form1.Designer.cs](<../Operations Control/Form1.Designer.cs>) | 创建顶部通信区、X/Y 位置、全局停止、主内容区、底部状态及定时器和文件对话框 | InitializeComponent |

Form1 中常用方法：

| 方法 | 作用 |
| --- | --- |
| IntegrateViews | 将 PathView、手动页、程序编辑器和日志嵌入同一个主窗口 |
| WireEvents | 把控件事件接入连接、运动、文件和窗口流程 |
| UpdateState | 根据连接、忙碌、点动、跟随、路径运行和关闭状态更新操作权限 |
| Run | 将控制器操作排入通信线程，完成后报告结果并恢复界面状态 |
| RefreshData / DisplayPosition | 查询手动反馈，更新读数、画布及顶部 X/Y；路径运行时顶部改用 PathView 的采样 |
| StartJog / StopJog | 开始和结束点动，保证快速按放时命令顺序正确 |
| BeginDrawing / PumpDrawing / CancelDrawing | 开始、提交和取消鼠标跟随 |
| StopMonitoredAxes | 路径运行时中止路径；其他情况下停止 X/Y 和所选电机 |
| SendCommand | 发送用户输入的单条命令并显示应答 |
| OpenProgram / SaveProgram / DownloadProgram | 读取、保存和下载自定义程序，处理编码及未保存内容 |
| Disconnect / CloseForm | 结束交互、请求停止、断开设备并处理关闭 |

PathView 中的主要方法：

| 方法 | 作用 |
| --- | --- |
| UpdateContext / SetExternalState | 接收主窗口的模式、轴号、标定和外部忙碌状态 |
| LoadDrawing / ImportDxf / AddShape | 加载笔画、导入 DXF 或添加典型图形 |
| InvalidatePlan | 图形或参数改变后清除旧规划和程序预览 |
| GeneratePlan | 获取输入与当前位置，后台调用 TrajectoryPlanner 生成规划 |
| StartExecution | 检查连接、配置和反馈，调用会话启动规划，建立本次运行记录 |
| Poll | 读取轴及坐标系状态，保存反馈、更新画布，判断完成、故障、越界和超时 |
| EnableAxes / StartHoming / MonitorHome | 发送使能/失能或回零请求，并监测本次回零状态变化和完成 |
| StopExecution / StopWithReason | 取消待启动任务，中止路径或回零，保留停止原因并执行完成回调 |
| Analyze / Export / SaveProgram | 计算统计、导出完整运行数据、保存规划程序 |
| Background / CancelPendingWork | 将解析、规划、分析和数据导出放在后台，关闭时使待处理结果失效并停止轮询 |

PathView 通过 ActivityChanged、StatusChanged 和 SnapshotChanged 向主窗口通知忙碌状态、消息和实时位置。

## 4. Models：数据与状态

| 文件 | 主要类型 | 功能 |
| --- | --- | --- |
| [ControllerModels.cs](<../Operations Control/Models/ControllerModels.cs>) | CommandResult、AxisSample | 保存并检查通信应答；保存电机号、位置、估算速度和采样时间 |
| [CanvasModels.cs](<../Operations Control/Models/CanvasModels.cs>) | MotionPoint、CanvasSettings、DrawPointEventArgs | 二维点、行程校验、屏幕↔mm↔ct 换算，以及画布点事件数据 |
| [JogRequestEventArgs.cs](<../Operations Control/Models/JogRequestEventArgs.cs>) | JogRequestEventArgs | 传递点动电机号和方向 |
| [DeviceStatus.cs](<../Operations Control/Models/DeviceStatus.cs>) | MotorStatus、CoordinateStatus、ControllerSnapshot、MonotonicClock | 解析 Turbo PMAC 状态，汇总 X/Y 反馈及查询时间，提供单调时钟 |
| [PathModels.cs](<../Operations Control/Models/PathModels.cs>) | DrawingPath、PlanningOptions、MotionSegment、PlannedStroke、MotionPlan、TrajectorySample、TrajectoryRun、InterpolationMode | 保存输入笔画、规划参数和轨迹段；按时间求位置/速度；保存本次运行及完整反馈 |

PathModels 中最常用的三个对象：DrawingPath 是原始图形，MotionPlan 是规划结果和生成程序，TrajectoryRun 是该规划的一次执行记录。停止后仍保留 TrajectoryRun，可继续分析和导出。

## 5. Services：通信、几何和算法

| 文件 | 功能 | 主要方法 |
| --- | --- | --- |
| [IControllerTransport.cs](<../Operations Control/Services/IControllerTransport.cs>) | 定义实机与模拟共用的连接、断开、命令、下载和释放接口 | Connect、Disconnect、Send、Download、Dispose |
| [PcommTransport.cs](<../Operations Control/Services/PcommTransport.cs>) | 适配 PCommServer.PmacDevice；选择/打开设备，通过 GetResponseEx 收发 ASCII 指令，通过 Download 下载文件，关闭并释放 COM | Connect、Send、Download、Dispose |
| [SimulatorTransport.cs](<../Operations Control/Services/SimulatorTransport.cs>) | 模拟 8 个电机的位置、点动、定位、状态、回零和按时间执行的双轴规划；支持滞后和故障注入 | Send、StartPlan、StopPlan、InjectFault |
| [ControllerSession.cs](<../Operations Control/Services/ControllerSession.cs>) | 创建 STA 通信队列，选择实机/模拟传输，组合 PMAC 命令，查询反馈，启动和停止路径及回零 | Execute、Jog、Move、ReadAxes、ReadSnapshot、StartPlan、StopPlan、Home、StopHome |
| [CanvasFollower.cs](<../Operations Control/Services/CanvasFollower.cs>) | 合并最新鼠标目标，限制同类请求积压，设置轴速度并提交双轴目标；取消旧任务并请求停止 | Begin、Submit、Pump、Cancel |
| [DxfReader.cs](<../Operations Control/Services/DxfReader.cs>) | 读取 ASCII DXF，换算单位，解析直线、圆弧、圆、多段线和样条，拒绝异常或不支持的输入 | Read、ReadText |
| [PathGeometry.cs](<../Operations Control/Services/PathGeometry.cs>) | 创建直线、圆弧/圆和五角星；校验、缩放、平移、重采样；计算距离及点到线段距离 | Line、Arc、Star、Validate、Transform、Resample、SegmentDistance |
| [TrajectoryPlanner.cs](<../Operations Control/Services/TrajectoryPlanner.cs>) | 将图形生成 PVT 或 Spline 规划；加入转移段，限制速度/加速度/段时间，检查曲线极值和行程 | Build |
| [PmacProgramWriter.cs](<../Operations Control/Services/PmacProgramWriter.cs>) | 将规划写成 PMAC 程序，包括轴比例、坐标系、程序号、时间单位、PVT/SPLINE1 和段间等待 | Write |
| [TrajectoryAnalysis.cs](<../Operations Control/Services/TrajectoryAnalysis.cs>) | 计算时间配对误差、轮廓误差、滞后和查询统计；导出输入、规划、反馈 CSV、报告和程序；同文件定义 AnalysisResult | Analyze、Export |

通信路径为：界面操作 → ControllerSession → PcommTransport → PcommServer → 已配置的以太网设备 → PMAC。模拟模式将 PcommTransport 换成 SimulatorTransport。

ControllerSession 的 Execute 负责排队与回调。Jog、Move、ReadSnapshot 等实际通信方法在该队列内执行；界面不直接调用 COM。

模拟器执行软件规划模型，不解释任意下载脚本。模拟下载成功只表示文件通过检查。

## 8. 主要调用关系与线程

| 操作 | 调用关系 |
| --- | --- |
| 启动 | Program.Main → Form1 → 创建 ControllerSession 和页面 → 绑定事件 |
| 连接 | ConnectionView 按钮 → Form1.Run → ControllerSession.Connect → 实机/模拟传输 |
| 手动运动 | MotionView 事件/按钮 → Form1 → ControllerSession.Execute → Jog / Move / Stop |
| 鼠标跟随 | MotionCanvas 事件 → Form1 → CanvasFollower → ControllerSession.MovePair |
| 图形规划 | PathView → DxfReader / PathGeometry → DrawingPath → TrajectoryPlanner → MotionPlan 和 PmacProgramWriter |
| 路径执行 | PathView.StartExecution → ControllerSession.StartPlan → 实机下载并启动，或模拟器执行规划 |
| 执行采样 | PathView.Poll → ControllerSession.ReadSnapshot → TrajectoryRun → 实际画布和顶部位置 |
| 分析导出 | PathView → TrajectoryAnalysis → AnalysisResult、CSV、报告和程序 |

界面线程负责控件、绘图和定时器事件；独立 STA 线程串行执行通信；BackgroundWorker 执行 DXF 解析、规划、分析和数据导出。后台结果交回界面线程，取消标记用于丢弃过期任务结果。

手动位置和步长使用 ct、速度使用 ct/ms；绘图和规划使用 mm、mm/s、mm/s²，轨迹时间使用 ms。实际 ct/mm 通过 CanvasSettings 换算。

## 9. 查找和修改入口

| 需要处理的内容 | 优先查看 |
| --- | --- |
| 主窗口布局 | Form1.Designer.cs；运行时整合看 Form1.IntegrateViews |
| 绘图/规划参数及页面 | PathView.Designer.cs、PathView.cs |
| 以太网设备连接问题 | PcommTransport.cs 和厂家 PcommServer 设备配置；当前无直接 IP 连接代码 |
| 运动命令和反馈 | ControllerSession.cs；电机/坐标系状态看 DeviceStatus.cs |
| 点动按放与操作互锁 | MotionView.cs、Form1.UpdateState、PathView.UpdateButtons |
| 比例和行程换算 | CanvasView.cs、CanvasModels.cs |
| CAD 导入 | DxfReader.cs |
| 插补算法和生成程序 | TrajectoryPlanner.cs、PmacProgramWriter.cs |
| 偏差、滞后和导出 | TrajectoryAnalysis.cs |
| 模拟行为与故障验证 | SimulatorTransport.cs、Tests 下两个检查程序 |

当前实机接口、状态和生成程序按 Turbo PMAC 实现，真实控制器型号尚未确认。手动运动统一保护、控制器侧断联停机、设备配置保存、轴方向/工件零点和 PLC 回零协议仍需完善；这些边界见 [软件开发问题与解决记录](软件开发问题与解决记录.md)。
