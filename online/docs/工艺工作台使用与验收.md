# 上位机操作与验收

本次按第三组分工表补齐上位机软件，采用用户确认的 ASCII DXF 范围。实机参数尚未提供，当前完成软件与模拟验证。

## 使用方法

1. 运行 `online/Operations Control/bin/Release/Operations Control.exe`，选择模拟模式并连接。
2. 在“绘图与运行”页导入 `online/examples/course-shapes.dxf`，或添加直线、圆、圆弧、五角星，也可在右画布自由绘图。
3. 选择 PVT 或 Spline1，设置速度、加速度和间距，点击“生成规划”。在“程序”页查看或保存规划程序，并编辑自定义程序。
4. 点击“运行”，左画布显示控制器反馈。顶部“停止”或 Esc 可中止；关闭程序会先请求停止。
5. 在“分析”页点击“分析”查看偏差与滞后，再“导出数据”。停止的数据会标为未完整运行。
6. “设置”页提供坐标参数、图形变换、使能、失能和机械回零。模拟演示保持 PLC = -1，选择目标轴后开始回零。“手动控制”和“日志”也在主窗口内。

运行期间锁定手动命令、模式和相关参数，切换页面仍可使用顶部停止。路径或规划参数改变后需重新规划。多笔画之间包含定位转移，当前没有抬笔或刀具开关控制。

## 输入与参数

DXF 支持 LINE、ARC、CIRCLE、LWPOLYLINE（含 bulge）、普通二维 POLYLINE，以及带控制点和节点矢量的非周期 SPLINE。按 `$INSUNITS` 换算单位；无单位文件使用界面指定比例。

DWG 需先转 ASCII DXF。块、文字/标注、三维、倾斜法向、周期样条和仅拟合点样条会明确报错，请在 CAD 中分解或转换后导入。图形平移改变输入点，不设置独立 G54 工件坐标系。

| 参数 | 默认值或规则 |
| --- | --- |
| 模拟标定 | X/Y 电机 1/2；100 ct/mm；各轴 −10～+10 mm |
| 速度 / 加速度 | 5 mm/s / 20 mm/s²；作为规划上限 |
| 点间距 | 0.5 mm，长边分段，保留原有转角 |
| DXF 采样弦差 | 0.01 mm；样条采用自适应近似 |
| 模拟滞后 | 80 ms，可修改 |
| 反馈请求间隔 | 50 ms，上一查询未完成时不积压请求 |
| 起点 / 终点检查 | 起点变化超过 0.01 mm 要求重规划；终点偏差超过 0.05 mm 报错 |
| 容量 | 输入/规划最多 20000 点或段，运行最多 1 小时，反馈最多 100000 点 |

这些是软件演示与检查参数，不是实机定位精度指标。真实速度、行程、比例和精度要求须按设备确定。

## 实现原理

流程为：输入图形 → 单位与坐标转换 → 路径校验 → 规划 → 程序预览 → 执行和采样 → 分析/导出。

GUI 采用事件驱动，输入变更使旧规划失效；连接、反馈、轴状态及实机配置决定操作是否可用。解析、规划和分析在后台计算；控制命令通过独立 STA 会话串行发送。

| 层次 | 职责 |
| --- | --- |
| 主窗口与路径模型 | 用户交互、笔画、运行状态及完整采样 |
| 几何、DXF、规划和分析服务 | 图形转换、轨迹计算、程序生成及误差统计 |
| ControllerSession | 命令组合、反馈读取、停止与取消 |
| IControllerTransport 的实机/模拟实现 | 屏蔽 PcommServer COM 与设备通信细节 |

上位机针对 Turbo PMAC。`#nP` 读取计数位置，`#n?` 读取电机状态，`&n??` 读取坐标系状态。计数除以 ct/mm 得到毫米；XY 顺序查询并各自记录查询中点时间，不是同步锁存采样。

鼠标跟随依次发送独立轴 `J=`。完整路径生成为坐标系程序，由控制器同步插补 XY：`#1->100X` 等语句定义轴比例；`ABS` 使用绝对坐标；PVT 指定位置、末速度及段时间，SPLINE1 使用等时三次 B 样条。程序使用 `I42=0` 和 `Isx90=1000`，单位为 mm、mm/s、ms。坐标系 1/9/10/16 的时间单位变量分别为 I5190/I5990/I6090/I6690。

PVT 在急转角停速，平滑段使用受限切向速度；规划器按速度/加速度界限延长时间，并检查曲线极值不越行程。Spline1 会圆滑转角，不保证经过每个输入点；模拟包含控制器自动增加的起止段。两种规划的单段时间均不超过 4000 ms。

`&nB程序号R` 启动，`&nA` 中止本次路径程序。完成判定同时检查程序结束、轴/坐标系到位、终点偏差和故障状态。模拟器执行数学规划，不解释任意下载脚本，实际固件执行仍需验证。

## 导出与分析

| 文件 | 内容 |
| --- | --- |
| drawing.csv | 原始采样点、笔画号 |
| planned.csv | 规划段起止位置、速度、时间与转移标记 |
| actual.csv | 反馈、每轴采样时间、参考位置、误差、查询耗时及来源 |
| analysis.txt | RMS/最大误差、滞后与采样统计、完成状态 |
| program.pmc | 本次运行对应的程序 |

数据独立于画布保存。时间配对误差按每轴查询中点计算“实际位置−同时刻计划位置”；轮廓偏差取反馈点到原始折线的最短距离，按计划排除转移阶段。前者包含跟随滞后，后者不能证明沿路径的时序或完整覆盖，转移边界附近的滞后也会影响统计。

滞后估计在 ±1000 ms 范围以 10 ms 步长匹配轨迹。样本不足、运动量过小或结果到达搜索边界时不给出可靠值；周期轨迹可能有歧义。已用 80 ms 已知滞后及 0.2 mm 已知偏移验证计算。

偏差主要来自图形离散、Spline 圆滑、标定、传动/伺服响应及通信采样。改进顺序为：核对单位与标定，调整点距及速度/加速度，使用控制器缓冲执行；精密验收采用控制器同步采集与量具。仅缩短界面 Timer 间隔不能消除通信和机械延迟。

## 实机待验收

需要确定控制器/固件型号、X/Y 电机号、ct/mm、轴方向、允许行程、回零参数、专用坐标系/程序号、PLC 号和精度指标。实机模式须重新应用标定并确认配置。

生成程序会定义所选轴映射、清空指定程序、设置全局 I42 及对应 Isx90；所选坐标系必须专用且没有其他轴。内置 HOME 使用控制器已配置的原点开关/Z 相与偏置；PLC 模式要求已部署 PLC 能按所选目标完成寻零、自行结束并支持禁用。界面观察本次寻零状态变化后，再确认 Home Complete、速度零和到位。HOMEZ 仅把当前位置设零。

现场仍需验证通信、标定、回零及重复性、双轴程序执行、停止/故障处理和真实轨迹精度。软件停止通过通信队列发送，不能替代硬件急停。本地成果也不能证明周报、Ego 云提交和现场汇报已完成。
