## 验证结果

- Debug、Release 编译通过，保持 .NET Framework 3.5 / x86。
- **130 项**基础检查与 **2273 项**工作流断言通过，包含主窗口整合、运行互锁、实时位置和最小尺寸检查。部分断言逐段检查轨迹边界，总数不是功能数量。
- 已知 80 ms 延迟恢复、0.2 mm 轮廓偏移、长于画布历史的 4101 条反馈导出、DXF→Spline GUI 完整执行、停止后不续跑、重复回零、回零取消/超时、关闭取消启动均有检查。
- 核对 Turbo SRM 的使能状态位、坐标系参数编号及运行错误状态；未用旧版 PMAC 位定义作为 Turbo 就绪判断。
- 已检查统一主窗口常规/最小尺寸、程序页、分析页和设置页的截图。

验证均使用模拟器，没有连接或操作实机。模拟器执行数学规划，不解释任意 PMAC 脚本，所以程序语法/固件时序与真实精度仍需现场验证。任意程序“模拟下载成功”仅代表文件检查，不能视为固件验收。
