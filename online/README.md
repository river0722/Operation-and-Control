# PMAC 上位机控制程序

C# WinForms，保留原生按钮、分组框、字体和画布样式，目标框架为 .NET Framework 3.5 / x86。绘图、手动控制、程序编辑、分析、设置和日志都在同一个主窗口中。

## 运行与编译

双击 `Operations Control/bin/Release/Operations Control.exe`，选择模拟模式，点击“连接”。实机需要已配置的 32 位 PcommServer / PMAC 驱动。

在 Visual Studio 中打开 `Operations Control/Operations Control.slnx` 或 `.csproj`，也可在本目录运行：

```powershell
.\build.ps1
.\build.ps1 -Configuration Debug
.\build.ps1 -Test -ScreenshotDirectory "$env:TEMP\pmac-verification"
```

## 操作

| 页面 | 操作 |
| --- | --- |
| 绘图与运行 | 导入 DXF、添加直线/圆/圆弧/五角星、自由绘图，生成 PVT/Spline1 规划并运行；左上方绘图，右侧实际轨迹 |
| 手动控制 | 受轴状态/行程保护的点动和定位、到位与停稳确认、速度写入回读、HOMEZ、每轴使能/去使能/复位 |
| 程序 | 查看/保存规划程序，编辑、保存、下载自定义程序，发送单条命令 |
| 分析 | 轨迹偏差、滞后、采样统计与完整数据导出 |
| 设置 | 坐标比例和行程、程序参数、图形变换、使能/失能、机械回零 |
| 日志 | 查看、清空和导出操作记录 |
| 诊断与配置 | 所选轴状态、跟随误差趋势、报警与恢复、设备配置保存/载入、按接线配置 I/O 查询 |

顶部通讯区始终显示连接模式和状态，底部固定显示 X/Y 位置、全局“停止”和报警，Esc 同样可停止。绘图页上方集中导入、撤销和清空工具，双画布下方排列图形参数、规划参数以及相邻的“生成规划”和“运行”按钮；这些工具不再占用其他页面。手动控制保留独立的“所选轴使能”和“所选轴去使能”。绿色、蓝色、黄色、红色分别配合文字显示就绪、处理中、反馈未知或条件不足、故障与限位，无报警为中性色。运行期间锁定相关参数和手动命令；关闭程序会先停止运动。所有页面共用通信会话和画布。

遇到“指令已停止，未到位”或停止确认卡住，可点击窗口底部的“解除等待并去使能”。确认机械支撑与抱闸后，程序取消原动作，对 X/Y 和所选监测轴去使能；连续新反馈确认去使能且位置稳定后解除等待，不要求到位位，原动作不会续跑。5 秒仍无法确认会明确报错；通信恢复后可重试，不会假定设备已恢复。

这次发现的脉冲输出通道冲突，可在去使能后点击“手动控制”页的“修复脉冲输出”。程序先核对本地 Turbo PMAC2 的 PFM 模式、内部计数反馈和通道映射，确认驱动器接线后只修正输出地址并回读；保持去使能，不自动启动、不执行 SAVE。之后主动点击“所选轴使能”。按钮沿用原有系统样式。

模拟默认电机 1/2、100 ct/mm、行程 ±10 mm、滞后 80 ms。绘图不自动运动；勾选“鼠标跟随”后按住左键跟随，松开、失焦或移出画布即停。鼠标跟随使用独立轴目标更新；完整路径运行使用坐标系 PVT/SPLINE1 插补。

DXF 支持 ASCII 格式的 LINE、ARC、CIRCLE、LWPOLYLINE、二维 POLYLINE 和非周期控制点 SPLINE，DWG 需先转换。不支持的实体明确报错。多笔画间包含定位转移，当前无刀具开关控制。

自定义程序优先按 UTF-8 读取，无法解码时尝试 GBK；修改后需保存再下载，下载不会自动运行。模拟器不解释任意下载脚本或用户 PLC。完整反馈独立保存，可导出原始点、规划段、实际反馈及误差 CSV、报告和程序。

## 项目文件

`Form1` 和 `Views` 负责界面交互与显示；`Application` 管理手动操作、路径执行、机械回零、共享操作状态和统一反馈；`Communication` 封装 PMAC 命令、实机/模拟传输及串行 STA 调度；`Motion` 负责几何、规划和误差分析；`Files` 负责 DXF、程序编码与文件读写、运行数据导出；`Models` 定义模块之间传递的数据。布局仍在原有 `.Designer.cs` 中，设计模式不会创建通信服务。

`build.ps1 -Test` 运行界面/模拟检查、工艺流程、模块和电机调试检查。检查包含第三轴故障、无响应超时、停稳确认、限位方向、配置读写与日志留存，不访问硬件。

软件及模拟检查通过，实机通信、标定、机械回零与精度尚待验收。软件停止通过通信队列发送，不能替代硬件急停。
